# ورود (Vorood)

PWA تغذیه با محور **ورودی کالری به بدن**.

بازار اول: ایران · بعد: عراق  
بدون بخش ورزش · سه سطح کاربر · ثبت غذا دستی + کاتالوگ + پیشنهاد AI

## اجرای محلی

```bash
cd vorood
npm install
npm run dev
```

باز کن: [http://127.0.0.1:3000](http://127.0.0.1:3000)

## MVP فعلی

1. آنبوردینگ + محاسبه کالری هدف (Mifflin-St Jeor)
2. صفحه امروز: هدف / خورده / مانده
3. ثبت غذا: کاتالوگ ایرانی، دستی، پیشنهاد AI
4. چت دستیار تغذیه (فعلاً provider fallback سمت سرور)
5. PWA manifest + قابل اجرا در مرورگر بدون نصب اجباری

## مقیاس (مسیر رشد، نه over-engineer امروز)

| لایه امروز | مسیر میلیونی |
| --- | --- |
| `localStorage` پروفایل/دفترچه | Postgres + API احراز هویت |
| کاتالوگ seed در کد | جدول `foods` + CDN/cache جستجو |
| `/api/ai/*` با fallback | LLM واقعی + rate limit + صف |
| یک سرویس Next | جدا کردن web و API در صورت نیاز |

قرارداد APIهای AI پایدار نگه داشته شده تا بدون تغییر کلاینت، provider عوض شود.
